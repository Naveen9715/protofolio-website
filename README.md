# 🌐 Naveen's Developer Portfolio

A responsive personal portfolio website showcasing full-stack web development projects, technical skills, and professional contact information.

## 🚀 Features

- **Hero Section**: Personal introduction and developer branding.
- **About Me**: Professional background and passion for software development.
- **Skills Showcase**: Highlights technical proficiency across front-end and back-end tools.
- **Projects Gallery**: Curated showcase of web development work and applications.
- **Interactive Contact Form**: Sleek contact form for client inquiries and collaboration opportunities.
- **Responsive Design**: Custom CSS styling with smooth layouts and modern styling.

## 🛠️ Built With

- **HTML5**: Semantic web structure
- **CSS3**: Custom styling, responsive flexbox layouts, and custom typography

## 📂 Project Structure

``text
├── port.html     # Main portfolio webpage structure
├── port.css      # Custom styling, responsive layouts, and themes
└── README.md     # Project documentation
``

## 💻 How to Run Locally

1. Clone the repository:
   ``bash
   git clone https://github.com/Naveen9715/protofolio-website.git
   cd protofolio-website
   ``
2. Open `port.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
